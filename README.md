# ir-analyzer

企業の一次情報（IR資料）を自動収集し、その範囲内だけで分析・壁打ちするツール。

現行版（Web）: https://ir-analyzer-beta.vercel.app/

## 目的

企業を一次情報で深掘りしたいとき、会社HPから資料を集める作業をなくす。

ネット上の二次情報は正確性の判断がつかない。だから公式資料に当たりたいが、
IRページを開いてURLを1つずつ探し、ダウンロードし、どこかに添付する作業が重い。
**この収集作業の自動化が本ツールの主目的。**

分析機能は副次的。参照するのは一次情報と、自分で選んだ公共性の高い資料のみ。

## 本命の要件（実装済み・ローカル限定）

`ローカル自動収集（PDFも保存）` ボタンから利用できる。詳細は以下の元要件と実装メモを参照。

### ローカルセットアップ

Vercelには無い、ローカル実行時のみ必要な追加手順：

```
npm install
npx playwright install chromium   # 初回のみ。ブラウザ自動操作用のChromiumを取得
npm run dev
```

分類の一部（ラベルだけでは判定できない資料）はClaude APIにフォールバックする。使う場合は `.env.local` に以下を設定（任意、未設定でも動作するが自動判定精度は落ちる）：

```
ANTHROPIC_API_KEY=sk-ant-...
```

収集したPDFは `~/Documents/IR資料/{会社名}/` 以下に保存される。

### 全自動（収集→要約→分析）

画面「1. 資料を取り込む」の **「全自動（収集 → 要約 → 分析）」** ボタンで、会社名とIRページURLを入れるだけで収集・保存・要約・分析まで一気に走る（要 `ANTHROPIC_API_KEY`）。

- 要約対象はコスト・時間を抑えるため **「最新の決算短信・決算説明資料・有価証券報告書」を自動選別**（種別ごとに最新年度・通期優先を1件ずつ）。
- 全資料を要約したい場合は、下記の個別ボタン（「取り込むだけ」→ 資料棚で選択 →「選択資料の要約を作成」）を使う。

### 要約・分析（手動・個別実行）

収集後、画面の「3. 要約・分析」から後段だけを手動で実行することもできる（要 `ANTHROPIC_API_KEY`）。

- **要約を作成**: 選択中の保存済みPDFを Opus 4.8 が**PDF本体のまま直接読み**（表・スキャン画像もビジョンで読む）、**原文引用＋出典ページ必須**の要約を `_要約/*.md` に生成する。数値は原文引用、読み取れない箇所は「判読不可」と明記し、知ったかぶりを構造的に防ぐ。
- **要約から分析**: 生成済みの要約だけを根拠に、アナリスト視点で事実と【所見】を分けた分析を `_分析/*.md` に生成する。

補足：

- ClaudeのPDF上限は約100ページ/32MB。**有価証券報告書など上限超の資料は、第1（企業の概況）・第2（事業の状況/MD&A）・第5（経理の状況）だけを自動抜粋**して収める。抜粋できない画像有報は「NotebookLM推奨」と表示。
- Opusで直接読むためトークン消費は大きめ。必要な資料だけ選んで実行する。
- 精度に納得できない場合は、要約を従来どおり NotebookLM 経由に戻す運用も可能（アプリは収集専用として使う）。

### 元の要件（未実装だった内容・設計方針として残す）

### 入力

- 会社名
- 証券コード
- IRページのURL（決算短信・決算説明資料などの一覧ページ）

### 処理

1. ブラウザを自動操作してページを開く
2. 年度セレクタがあればすべての年度を順に選択し、PDFリンクを収集する
3. PDFをダウンロードする
4. 中身を読んで資料種別・決算期・四半期を判定する
5. リネームして企業ごとのフォルダに保存する

   例）`守谷輸送機工業/守谷輸送機工業_2026年3月期_第2四半期決算短信.pdf`

### IRページの3パターン

- A. 静的に全件並んでいる（過去10年分など）… 現行方式でも取得可能
- B. 年度セレクタで選択して表示（守谷型）… 現行方式では取得不可
- C. タブ・アコーディオンで切り替え … リンクが最初からHTMLにあれば取得可能

ブラウザ自動操作方式にすれば A・B・C を同じ処理で扱える。
パターンごとに分岐を書くのではなく、人間の操作を再現する方針とする。

### 重要な制約

**Vercel上のWebアプリでは実現できない。**
ブラウザを操作できず、ローカルフォルダにも保存できないため。
手元（Mac）で動くツールとして作り直す必要がある。

現行版の画面・資料棚・質問機能はそのまま流用可能。

### 動作確認用ページ

年度セレクタ方式。現行方式では会社案内PDFしか取得できない。
ここで短信4件・説明資料4件が取得できれば、本命の要件を満たしたと判定できる。

- https://moriya-elevator.co.jp/ir/library/results/ （決算短信・4件）
- https://moriya-elevator.co.jp/ir/library/presentations/ （決算説明資料・4件）

### 収集後の使い道

整理済みPDFのフォルダができれば、その先は自由に選べる。

- NotebookLMに投入して読解・壁打ち（表の読み取り精度が高い）
- 本ツールで質問（出典・原文引用の強制ができる）

## 現行版（実装済み・Vercel）

### 使い方

1. IR資料の一覧ページのURL、またはPDFのURLを最大3つ入力して「取り込む」
2. 資料棚に入ったPDFから、不要なもののチェックを外す
3. 選択中の資料だけを根拠に質問する

### 構成

- Next.js (App Router / JavaScript)
- TypeScript・Tailwindは不使用（意図的にシンプル構成）
- GitHubにコミット → Vercelが自動デプロイ
- 環境変数 `ANTHROPIC_API_KEY` はVercel側に設定（リポジトリには含めない）
